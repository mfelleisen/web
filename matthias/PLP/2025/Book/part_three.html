What does a machine for executing code look like?

Well-formed sentences have meaning.

How do we figure out the meaning of the AST of a well-formed program?

- pure expressions deliver a value: addition

- pure statements modify memory (typical while loops or conditionals) but what’s memory?

- (pure statements may also read inputs, write outputs)

- some languages conflate expressions and statements so that they have effecs on memory and return values; see C’s assignment statements
