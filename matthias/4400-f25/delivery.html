—Delivery🔗

Operating System All software must run on Linux machines like those provided by the College of Computer Science. As you may know from when you signed up for CCIS accounts, you may log into the Linux machine called

     login-students@ccs.neu.edu

or

     login-students@khoury.northeastern.edu

which runs the standard operating system. The College also provides virtual Linux machines with the same configuration.

You are welcome to develop code on your laptops. If you do, git-pull on a Linux box and make sure that you can run your programs there, too. (That’s the sixth step of the design recipe, applied to non-coding contexts.)

Project Submission All of your work will live on your github account. On the specified due date and time, a script will harvest your work.

Your assigned github account is your only means to submit projects.
